**Open subtitles or a transcript for a video at any time, correct the words, and save them back.**

- **Open saved subtitles or a transcript** (on the first screen and the results screen): pick the
  video, then the file. It plays with the lines at their times, without running Whisper again.
  Besides the app's own subtitle files (.srt), it opens:
  - subtitles from other apps: .vtt (Zoom, Teams, YouTube) and .sbv (YouTube);
  - a transcript or minutes with times in it, as a text file (.txt) or a Word document (.docx):
    a time at the start of each line or paragraph (like `01:23`, `[00:01:23]` or `(1:23) -`), a
    time on its own line with the words under it, or a speaker's name followed by a time. Each
    line shows from its time until the next one starts (or for as long as it takes to read, if
    the next one is much later). Anything before the first time, like a title or a date, is left
    out.
  - If the times in the file are later than the end of the video (clock times, like a meeting's
    10:00), the first line is moved to the start of the video. Use **Subtitle timing** to move
    them all from there.
- **Correct the words and save them into the same file.** After opening a .srt, correct lines in
  **See and correct the words**, then tap **Save changes in (file name)**. If you leave the video
  with corrections not saved, the app asks first. A transcript that is not a .srt is saved as a
  new .srt (with **Save subtitles**); later corrections then go into that file.
- **Save text** now writes a time before each line (`[00:01:23] words`), so the text file opens
  again with the video too. The .srt is still the exact one: it keeps when each line ends.
- When you save a copy of the video with the subtitles burned in, the app now reminds you to also
  save the subtitles (.srt): the words in the copy are part of the picture and cannot be read back
  to correct later.

Still no internet permission, and nothing is kept except where you save it (and the one
translation the app keeps until you close it).

To install: download the `.apk` below on the phone and install it over the previous version.

video still becomes the right English (with the language model too) and a copy is still made with
