**Open saved subtitles from the results screen too.**

The button **Watch a video with subtitles you saved** was only on the first screen, which the app
leaves after a translation. It is now also on the results screen. Tap it, pick the video, then pick
the `.srt` file you saved for it: the video plays with those subtitles straight away, without
translating again, and you can change their look, correct lines and save a copy as usual.

To install: download the `.apk` below on the phone and install it over the previous version (same
app, nothing to load again).

Checked before release: no network permission; signed with the release key; on an emulator a real
video still becomes the right English, with the language model too, and a copy is still made with
the subtitles burned in.
