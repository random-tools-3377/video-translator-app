**Keeps translating in the background.** This is a new copy of Video Translator with a new app
ID, so it installs **beside** the old one rather than over it.

To switch over:

1. Download the `.apk` below on the phone and install it. You will see two Video Translator apps
   for now.
2. Open the new one and load the language model again (**2. Load the downloaded file**). If the
   model file you downloaded before is still in your Downloads folder, pick that; there is no need
   to download it again. The new app keeps its own copy, so for a while the phone needs room for
   two. If it says there is not enough space, open the old app, tap **Remove it** under the
   language model, and try again.
3. Translate a video in the new app. Once that works, uninstall the old Video Translator
   (press and hold its icon, then **Uninstall**).

What's new: a long video no longer stops when you switch to another app or the screen turns off.
While it works, a notification shows the video's name and how far along it is, with a **Cancel**
button. Tap the notification to come back to the app. When it has finished, a second notification
says so.

The first time you start a translation, Android asks whether Video Translator may show
notifications. Say **Allow** so you can see the progress; it keeps working either way.

The app still has no internet permission. To keep working with the screen off it uses Android's
"foreground service" (the notification) and keeps the processor awake while it works; neither
lets it go online, and the build check still refuses any network permission.

If the phone still stops it on a long video: Settings > Apps > Video Translator > Battery >
Unrestricted.

Checked before release: no network permission (and only these background permissions added);
signed with the release key; on an emulator a real video still becomes the right English, with the
language model too. Not checked: running in the background on a real phone with the screen off;
the emulator cannot show that. Speed is unchanged; making the transcription faster is the next
step.
