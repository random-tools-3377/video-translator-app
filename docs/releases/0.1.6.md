**Writes down the speech faster when the language model is loaded.**

With a language model loaded, Whisper first writes down what is said in the video's own language,
and the language model then translates it. Whisper now does that writing-down with a quicker
search: on the test recordings (two Japanese, two Russian) it wrote exactly the same words as
before in about 20% less time, so the English came out the same. How much faster it is on the
phone is not known until you try it; the translating part takes as long as before.

Without a language model nothing changes: Whisper still translates with the slower, more careful
search.

Also in this version (from 0.1.5): translating keeps going when the app is off the screen.

To install: download the `.apk` below on the phone and install it over the previous version (same
app, nothing to load again).

Checked before release: no network permission; signed with the release key; on an emulator a real
video still becomes the right English, with the language model too; on the PC test machines, the
public clips still give the right English. Not checked: speed on a real phone.
