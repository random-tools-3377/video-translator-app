**A translation that gets stopped can carry on, and a finished one is still there tomorrow.**

Android allows long work in the background only for a while (about 6 hours a day), and it can also
close apps when the phone needs memory. Until now that lost everything. Now:

- While it works, the app keeps what it has done so far in its own private storage. If it is
  stopped, open the app: it shows what was done and **Carry on from where it stopped** finishes the
  rest. Whisper starts again from the last finished line (it reads the sound again first, which
  takes a minute or so), and the language model translates only the lines it had not done yet.
- A finished translation, with your corrections, is also still there after the app was closed.
- If the app is no longer allowed to open the video (for example after the phone restarted, or for
  a video shared from the Gallery), it asks you to pick the same video again, and checks it is the
  same one.
- **Close this result** (on the results screen) forgets it and goes back to the start. Starting
  another video also replaces it. Only the one translation is kept.

About privacy: the kept work (the lines and their times) is stored only inside the app. Nothing
else can read it, it is never backed up, and it is deleted when you close the result or start
another video. To read the video again later, the app keeps permission to open that one video
until then. Still no internet permission.

For a long video overnight, keeping the app open on screen with the phone plugged in is still the
fastest: Android's background limit does not apply then.

To install: download the `.apk` below on the phone and install it over the previous version (same
app, nothing to load again).

Checked before release: no network permission; signed with the release key; on an emulator a real
video still becomes the right English, with the language model too; a copy is still made with the
subtitles burned in; and the kept work comes back as it was, and Whisper carries on from the last
kept line without redoing what was done. Not checked: a real stop on the phone (overnight).
